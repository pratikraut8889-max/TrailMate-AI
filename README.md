# TrailMate AI

**Turn spare time into an outdoor adventure.**

TrailMate AI is an AI-powered web application that creates personalized outdoor adventures based on a user's preferred activity, available time, and mood.

### Key features
- AI-generated outdoor adventures powered by Groq.
- Five activity choices and three mood options.
- Adventure durations of 20, 30, 45, or 60 minutes.
- Bite-sized missions with estimated durations.
- Interactive mission completion and live progress tracking.
- Responsive interface with animations and completion celebrations.

### Technology stack
Next.js, React, TypeScript, Tailwind CSS, Zod, and the Groq API.
